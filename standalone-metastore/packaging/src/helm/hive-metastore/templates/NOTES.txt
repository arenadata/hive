Hive Metastore is running in namespace {{ .Release.Namespace }} with {{ .Values.replicas }} replica(s),
on {{ if .Values.postgres.enabled }}the chart's PostgreSQL {{ include "hive-metastore.postgresName" . }}{{ else }}the database {{ include "hive-metastore.db.url" . }}{{ end }}.

Clients connect to it with these properties in hive-site.xml:

  hive.metastore.uris                    {{ include "hive-metastore.uri" . }}
  hive.metastore.uri.resolver            org.apache.hadoop.hive.metastore.hooks.DnsURIResolverHook
  hive.metastore.uri.selection           RANDOM
  hive.metastore.client.socket.lifetime  600s
{{- $auth := include "hive-metastore.authType" . }}
{{- if eq $auth "KERBEROS" }}
  hive.metastore.sasl.enabled            true
  hive.metastore.kerberos.principal      {{ .Values.auth.kerberos.principal }}
{{- else if include "hive-metastore.authPlain" . }}
  hive.metastore.client.auth.mode        PLAIN
  hive.metastore.client.plain.username   <user>{{ if eq $auth "CONFIG" }} ({{ .Values.auth.config.username }}){{ end }}

The client reads the password of <user> from the Hadoop credential provider
(hadoop.security.credential.provider.path), with the user name as the alias:

  hadoop credential create <user> -provider jceks://file/<path>/hms.jceks
{{- end }}

Result of the schema Job:

  kubectl -n {{ .Release.Namespace }} logs job/{{ include "hive-metastore.name" . }}-schema-{{ .Release.Revision }}
